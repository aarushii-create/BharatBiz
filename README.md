# BharatBiz AI

BharatBiz AI is a multilingual, voice-first business decision assistant for Indian small retailers. It turns sales, inventory, and expense data into deterministic evidence, recommendations, and approval-gated purchase actions.

## Run Locally

Prerequisite: Node.js 20+

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The command starts both the Vite web app and the local API server.

Create an account to begin with an empty workspace. No API key is required for the core product path. Business records are stored in the local `server/data.json` file, which is intentionally ignored by version control. Optional provider credentials can be configured through environment variables described in [.env.example](.env.example).

## Verify Before Submission

```bash
npm run lint
npm test
npm run build
```

The automated suite covers deterministic business calculations, AI intent and tool selection, multilingual text and voice fallback, CSV validation, failure handling, edge cases, approval safety, and audit trails. Measured results from the latest run are recorded in [TEST_REPORT.md](TEST_REPORT.md).

## Product Flow

1. Ask a business question in English, Hindi, Tamil, or Telugu.
2. Review deterministic evidence from sales, expenses, and inventory.
3. Inspect the recommendation and proposed purchase order.
4. Approve or reject the consequential action explicitly.
5. Review the resulting purchase order and audit trail.

## Submission Notes

- Financial calculations are performed by deterministic services, not generated by the language layer.
- Unsupported questions and unavailable data return safe responses without fabricated metrics.
- Purchase orders are not committed until a human approves them.
- Live LLM-provider reliability and subjective voice naturalness are not measured. The current product path uses deterministic analysis and a provider-ready API boundary.
